# 레벨 — 분야 과정

상위 문서: [전체 개발 과정](../../../PROCESS.md)

## 목표

전투가 이뤄지는 공간을 만든다. 맵 생성은 던전 생성기로 진행한다(2026-11-16 개발자 결정).

[초기 게임 기획서](../../TopDownBase_Initial_Game_Plan.md)는 아직 "고정 전투 방 3개"와 "절차적 생성 MVP 제외"로 적혀 있다. 기획서 반영 여부는 개발자가 결정한다.

## 기능별 현황

| 기능 | 상태 | 다음 단계 | 문서 |
| --- | --- | --- | --- |
| 던전 생성 프로토타입 (MVP 범위 밖, 탐색용) | 구현·AI 검증 완료. 개발자가 배치와 동작 확인. 에디터 생성 버튼은 개발자 확인 필요 | 인스펙터 버튼 직접 확인 | [과정](DungeonGenerationPrototype/Process.md) · [구조와 사용법](DungeonGenerator_Guide.md) |
| 고정 전투 방 3개 | 확인 필요 | 착수 시 문서 연결 | — |

던전 생성 프로토타입은 플레이어 조작·적 구현에 의존하지 않고 단독으로 실행된다. 방 잠금과 적 스폰 연동은 해당 기능이 만들어진 뒤에 가능하다.
