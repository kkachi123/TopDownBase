# 레벨 — 분야 과정

상위 문서: [전체 개발 과정](../../../PROCESS.md)

## 목표

전투가 이뤄지는 공간을 만든다. [초기 게임 기획서](../../TopDownBase_Initial_Game_Plan.md) 기준으로 플레이마다 생성되는 자연환경 던전(공터로 된 전투 방·아이템 방과 그 사이의 굽은 길)과 별도 씬의 보스 투기장으로 구성하며, 던전은 던전 생성기로 만든다. 던전의 보스 입구 방에서 포털로 보스 씬에 이동한다.

## 기능별 현황

| 기능 | 상태 | 다음 단계 | 문서 |
| --- | --- | --- | --- |
| 던전 생성기 (현재 프로토타입) | 2026-11-18 벽 방식에서 자연환경 방식으로 대체. 방 배치·열쇠·포털·입구 잠금·적 스폰 위치가 자연환경에서 동작(AI 검증, 개발자 확인 2026-11-18). 환경 세팅 에셋으로 분위기 교체 가능(AI 검증, 개발자 확인 2026-11-18). 보이지 않던 그림자를 꺼 DrawCall 감소 | 기본 환경 선택 | [구조와 사용법](DungeonGenerator_Guide.md) · [자연환경 과정](NatureEnvironment/Process.md) · [이전 벽 방식 기록](DungeonGenerationPrototype/Process.md) |
| 보스 투기장 (보스 씬) | 확인 필요. 현재 포털은 `SampleScene`을 불러온다. 규격은 미확정 | 착수 시 문서 연결 | — |
| 자연환경 맵 (공터 + 길 + 자연물 경계) | 진행 중. 1~4단계 완료(AI 검증, 개발자 확인), 3단계 결과 기획서 반영. 그림자 끔(화면에 보이지 않던 그림자, DrawCall Forest 96·PineHighland 154) | 5단계는 플레이어·적 구현 뒤 | [계획](NatureEnvironment/Plan.md) · [과정](NatureEnvironment/Process.md) |

던전 생성기는 플레이어 조작·적 구현에 의존하지 않고 단독으로 실행된다. 방 잠금과 적 스폰 위치는 준비돼 있고, 실제 적 생성과 전투 시작·종료에 따른 잠금은 해당 기능이 만들어진 뒤에 연결한다.

## 실험

기획에 포함되지 않은 배치 테스트다. 경계를 Terrain이나 자연물 소품으로 표현해 본 결과는 [맵 경계 표현 테스트](LayoutTests.md)에 있다. 자연물 방식이 던전 생성기로 옮겨지면서 테스트 코드와 씬은 지웠다.
